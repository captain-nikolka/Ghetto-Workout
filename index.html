Все тренировки

Экспорт

CSV: одна строка на каждый выполненный подход, разделитель запятая, кодировка UTF-8. Открывается в Excel, Google Таблицах и Numbers.

Расчёт тоннажа

Тоннаж = повторы × вес в повторе. Для каждого выполненного подхода: вес тела в этот день, минус помощь резинки или доля веса для австралийских, плюс дополнительное отягощение. Висы и удержания учитываются по времени, лопаточные подтягивания по повторам, без тоннажа.

Свои упражнения

Для зала с ноября: добавь упражнение, и оно появится в списке при записи тренировки.

Синхронизация через GitHub

Тренировки сохраняются в файл workouts.json в твоём приватном репозитории с данными (отдельном от сайта). Токен хранится только в этом браузере, его нужно ввести один раз на телефоне и один раз на компьютере.

Резервная копия

При загрузке данные объединяются: более свежая версия каждой тренировки побеждает.
