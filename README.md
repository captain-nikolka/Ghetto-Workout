# Турник 30 — как выложить на GitHub Pages

Займёт около 10 минут. Всё бесплатно на тарифе GitHub Free.

Нужны **два репозитория**:

| Репозиторий | Видимость | Что внутри |
|---|---|---|
| `turnik` | **Public** | Сама страница: `index.html` и `.nojekyll` |
| `turnik-data` | **Private** | Твои тренировки (`workouts.json`), страница создаст файл сама |

Почему два: на бесплатном тарифе GitHub Pages публикует сайт только из публичного
репозитория. Сама страница не содержит твоих данных, а тренировки лежат в приватном
репозитории, и их видишь только ты.

## 1. Репозиторий для сайта

1. github.com → **New repository** → имя `turnik`, **Public**, поставь галочку **Add a README file** → **Create**.
2. **Add file → Upload files** → перетащи `index.html` и `.nojekyll` → **Commit changes**.
   (Если `.nojekyll` не виден в проводнике, его можно пропустить, сайт работает и без него.)
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/(root)** → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ЛОГИН.github.io/turnik/`.

## 2. Репозиторий для данных

1. **New repository** → имя `turnik-data`, **Private**, галочка **Add a README file** → **Create**.

## 3. Токен для синхронизации

1. Аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Name: `turnik`. Expiration: например, 1 год.
3. Repository access: **Only select repositories** → выбери **turnik-data**.
4. Permissions → Repository permissions → **Contents: Read and write**. Больше ничего не нужно.
5. **Generate token** и скопируй его (`github_pat_…`). GitHub покажет его только один раз.

## 4. Подключи страницу

На телефоне и на компьютере: открой сайт → **Настройки → Синхронизация через GitHub**:
- Репозиторий с данными: `ЛОГИН/turnik-data`
- Токен: вставь `github_pat_…`
- Ветка: `main`

Нажми **Сохранить и синхронизировать**. Индикатор вверху станет зелёным.

Тренировки сохраняются на устройстве сразу и уходят в GitHub через секунду после изменения.
Без интернета всё работает и досинхронизируется при следующем открытии.

## Приватность

- Страница помечена `noindex`: поисковики её не индексируют.
- Адрес сайта при этом открыт для любого, кто его знает. Закрыть сайт паролем на GitHub
  можно только на корпоративном тарифе Enterprise Cloud. Но без твоего токена посторонний
  увидит пустой шаблон без твоих тренировок.
- Токен хранится только в браузере устройства и даёт доступ только к `turnik-data`.
  Не вводи его на чужих устройствах. Кнопка «Отключить» удаляет токен из браузера.

## Если что-то не так

| Сообщение | Что сделать |
|---|---|
| Токен не подходит или истёк | Создай новый fine-grained токен (шаг 3) |
| Репозиторий не найден | Проверь путь `логин/turnik-data` и что токен выдан на этот репозиторий |
| Токену не хватает прав | В токене нужно Contents: Read and write |
| Нет связи с GitHub | Данные сохранены на устройстве, синхронизируются позже |
